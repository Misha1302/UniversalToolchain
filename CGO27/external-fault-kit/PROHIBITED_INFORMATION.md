# Information that must not be disclosed before freeze

Do not disclose to the external author:

- P0/P1/P2/P3 outcome matrices;
- identifiers, source or expected answers from existing primary, challenge or holdout faults;
- implementation code for model-authored fault injectors;
- raw JSONL, summaries, diagnostics or timing results from any policy run;
- which faults selective verification currently misses or catches;
- reviewer findings derived from executing candidate external cases.

Permitted information is limited to the public architecture, public SDK/API documentation, case schemas and generic examples that are not executable corpus answers.
