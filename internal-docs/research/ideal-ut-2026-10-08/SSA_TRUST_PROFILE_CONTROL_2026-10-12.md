# Protocol amendment A4: test the default SSA optimizer profile

**Triggered by independent source review after the first 504/504 Core run, before changing the fixture.** The frozen [preregistration](SSA_TRUST_PREREG_2026-10-12.md) never asserted that an arbitrary user descriptor is installed in the default Wist pipeline. Reading `SsaRouteProfiles.Create`, `SsaArithmeticInt32Pack.CreateOptimizationPasses`, `SsaManagedCallablePack`, `SsaRouteFactory.CreateOptimizer` and `SsaOptimizerModule` exposes an important rival explanation: the stock profile selects a fixed descriptor set for optimization, and the managed pack creates no independent optimization passes. SSA structural verification can recognize execution-bound managed descriptors without giving DCE the same authorization.

**Additional control, not a retroactive replacement of earlier cases:** inside the already-registered adverse test, run the same preconstructed `SsaArtifact` through `SsaRouteFactory.CreateOptimizer(SsaRouteProfiles.Create(SsaRoutePolicy.Prefer))` without injecting the method's declared descriptor into pass configuration. Assert that the call **remains**. This keeps the same four NUnit test methods and exact manifest (504 / 1328); no added independent pass/handler. If the default route removes it, record a stronger finding instead of silently suppressing it. Keep separate traces for explicitly injected descriptor versus stock profile.

**Interpretation gate:** unsafe elimination with manually supplied descriptors demonstrates a public low-level API trust assumption. If the stock profile retains the call, the experiment does **not** establish an unsafe default Wist optimizer path. Do not promote a host-policy API change until the real Wist `LanguagePlan` path is examined and open-world selection requirements are concrete. Stock profile acceptance of an isolated SSA artifact is still not full end-to-end AIR→SSA→AIR execution; that remains outside this experiment.

No original pre-registration content or production compiler source is changed. Only the new isolated NUnit fixture and dated outcome memo may change.
