# Idea register: adopt / prototype / defer / reject

Research choices are reversible. The right result may be **not** adopting an abstraction.

| Idea | Disposition | Competitive control or activation criterion |
| --- | --- | --- |
| Read-only typed `LanguagePlan`/diagnostics projection | TRY | Existing plan must remain only selection owner; compare against good docs/debugger |
| Independent negative mutation and oracle manifest | TRY | Value/exception/heap/effect and checked overflow, not parity of two implementations sharing a bug |
| Exact plan+implementation+program evidence identity | PROTOTYPE | provider SHA/revision swap invalidates stale claims |
| Scoped fact/query with four-valued outcome and provenance | PROTOTYPE | E1 succeeds with 0 edits to consumer, no false-safe result, beats direct interface |
| Minimal shared typed predicate vocabulary | CONDITIONAL | Actual N+1 authoring must need it; no hundreds of primitive synonyms |
| AST↔AIR/SSA evidence transfer | PROTOTYPE AFTER E1 | independently checked one-to-many translation and observation scope |
| Selected-route freeze/specialization | PROTOTYPE AFTER E1 | bound hot path has no per-call registry/fact lookup, with measured amortization |
| Causal Explain/why-not and deterministic Preview | TOOLING-SIDE ONLY | derived from existing plan/diagnostics, not a second resolver |
| Typed operation declaration + optional generator | PROTOTYPE | held-out authoring reduces glue; ordinary C# remains escape hatch |
| DSL grammar/binder, LSP and tooling | PRODUCT PATH | real independent non-Wist author and editor workflow |
| Declarative rewrite rules | DEFER / LIMITED | only mechanically checkable laws, subject to FP/overflow/effects |
| General rule engine / semantic graph | DEFER | ≥2 separate true transitive uses, bounded joins, clear evidence value |
| Full dependency/version solver, persistent planner cache | DEFER | measured ecosystem or planning bottleneck first |
| AI/MCP semantic query projections | OPTIONAL ADAPTER | read-only, versioned, scoped, independent oracle, measurable end-user value |
| Second LanguageCompiler, mandatory SSA | REJECT | violates owner/representation neutrality |
| AI-generated proof accepted as truth | REJECT | circular verification and undefined trust |
| Universal zero-cost and universal compatibility claims | REJECT | not supported by experiments |
| Valid `LanguagePlan` as hostile plugin sandbox | REJECT | needs process/OS isolation and separate threat model |

Potential prior-art controls: typed .NET interfaces/hand-coded pipeline; MLIR ODS/interfaces/PDLL/conversion; Silver/ableC and JastAdd; LLVM New PM; Salsa; Alive2; egg/e-graphs; Soufflé provenance; Truffle; MPS; Calcite. Typed facts, Datalog, SSA and source generators are **not new inventions**. Possible distinguishing result: independently authored cross-layer semantic interop with exact validity, measured against strongest controls. Scientific novelty is currently **UNPROVEN**.
