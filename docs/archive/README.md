# Documentation archive

This directory contains historical material that is useful context but is not
current runtime truth.

Archived documents may describe removed behavior, early product thinking, or
future-facing plans that were not implemented on this branch. Do not use them as
acceptance criteria unless a current canonical document links to them explicitly.

Current architecture truth starts with:

- `docs/CURRENT_ARCHITECTURE_STATUS.md`
- `docs/ARCHITECTURE_RULES.md`
- `docs/PROJECT_RULES.md`
- `docs/DOCUMENTATION_RULES.md`
