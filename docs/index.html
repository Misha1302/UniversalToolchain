Universal Toolchain

Мета-система для создания расширяемых языков программирования, решающая трилему языкового дизайна через модульную архитектуру и расширяемое промежуточное представление

Исходный код Демо Wist

Проблема: трилема языков программирования

Фиксированные языки программирования не могут одновременно обеспечивать:

  • Выразительность — интуитивные абстракции, минимизация boilerplate-кода
  • Производительность — генерация оптимального машинного кода
  • Специализацию — адаптация под конкретные предметные области

Python и JavaScript жертвуют производительностью ради выразительности. C++ и Rust требуют сложности для высокой производительности. Создание предметно-ориентированных языков (DSL) остается неподъемной задачей для большинства проектов.

Пример: семантический разрыв в C# ▼
Проблема: отсутствие обобщенной арифметики в C# 9.0 (используется в unity на момент 17.12.2025)
// В идеальном мире unity:
T SquareMagnitude<T>(T a, T b) where T : Number => a * a + b * b;

// В реальности приходится:
double SquareMagnitude(double a, double b) => a * a + b * b;
float SquareMagnitude(float a, float b) => a * a + b * b;
// Дублирование для каждого числового типа...

Решение: модульная архитектура и шитый код

Universal Toolchain декомпозирует традиционный компилятор на независимые модули:

Ядро системы — интерфейс ICoreModule
public interface ICoreModule
{
    void InitLexer(ILexer lexer);
    void InitParser(IParser parser);
    void InitTranslator(IBytecodeTranslator translator);
    void InitExecutor(IExecutor executor);
    // Каждый этап компиляции — отдельный модуль
}

Шитый код (Threaded Code) — универсальное промежуточное представление, сохраняющее семантику на всех этапах компиляции:

Структура байткода
public record BytecodeInstruction(
    HashSet<string> Tags,
    LevelCollection<float, IDynamicMethodConvertable> Ops
);

Модули добавляют операции в слоты с приоритетами (например, проверка границ в ops[-1.0f], логирование в ops[1.0f]), не зная о существовании друг друга. Это решает проблему O(N²) связности.

Язык Wist: реализация и демонстрация

На базе Universal Toolchain создан полнофункциональный язык Wist с поддержкой переменных, условий, циклов и интероперабельности с C#.

Пример кода на Wist: сумма чисел от 0 до 99
// Классический цикл с метками
let result = 0
let i = 0
@start:
    result = result + i
    i = i + 1
    if i < 100
    goto @start
result

Logs Viewer — веб-инструмент для визуализации всего процесса компиляции:

Визуализация этапов компиляции:

  • Исходный код → лексемы
  • Лексемы → абстрактное синтаксическое дерево (AST)
  • AST → промежуточный байткод Universal Toolchain
  • Байткод → CIL (.NET) или интерпретация

Интерактивная связь между этапами: клик на CIL инструкции подсвечивает соответствующий байткод.

Ключевые особенности

Модульность

ICoreModule позволяет подключать независимые модули для каждого этапа компиляции. Язык Wist — композиция 15+ модулей.

Расширяемое представление

Шитый код (Threaded Code) сохраняет семантику и обеспечивает линейную связность между модулями (O(N) вместо O(N²)).

Двойная система исполнения

Интерпретатор для отладки + CIL-компилятор для производительности. Оба работают с единым байткодом.

Расширяемая система типов

Интерфейсы и система контрактов позволяют добавлять новые типы без изменения ядра.

Готовый язык Wist

Поддержка переменных, условий, циклов, goto, вызовов C#. Реализованы простейшие алгоритмы (Фибоначчи, сортировка).

Инструменты отладки

Logs Viewer, логгер компиляции, 74 теста с покрытием 85%, система обработки ошибок.
