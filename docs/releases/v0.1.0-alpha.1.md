# UniversalToolchain.Wist 0.1.0-alpha.1

Первая alpha-версия после архитектурного hardening-прохода.

## Основные изменения

- типизированные и неизменяемые AIR-инструкции;
- одинаковая обработка типизированного `null` в interpreter и CIL;
- строгая проверка терминального состояния стека;
- обязательная stack-семантика extension intrinsics;
- единый managed-call descriptor для analysis, SSA и backend-ов;
- исправленный CFG fallthrough последнего условного перехода;
- атомарная загрузка lexer-конфигурации;
- безопасный lifecycle подготовленной программы;
- детерминированная capability composition;
- изолированное кэширование runtime для каждого DI-контейнера;
- ленивое создание только выбранного backend-а.

## Проверка

- 75/75 проектов репозитория собираются;
- 0 предупреждений компилятора;
- 0 ошибок компилятора;
- 1 325 тестов пройдено;
- 0 падений;
- 0 пропусков.

## Ограничения alpha-версии

- API может изменяться до стабильного релиза;
- restricted dialects не являются hardened sandbox;
- гарантии производительности относятся к скомпилированному typed fast path,
  а не ко всем режимам исполнения;
- third-party module/backend authoring остаётся экспериментальным.
